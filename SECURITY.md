# Güvenlik politikası

Bu depo, üretimde kullanılan bir sistemin anonimleştirilmiş portföy
kopyasıdır. Canlı sisteme ait adres, veri veya anahtar içermez.

## Güvenlik açığı bildirimi

Bir güvenlik açığı bulduysanız lütfen **herkese açık issue açmayın**.
Bunun yerine bu deponun **Security** sekmesindeki
**"Report a vulnerability"** bağlantısını kullanın. Bildirim yalnızca depo
sahibine görünür.

Desteklenen sürüm: yalnızca `main` dalının son hâli.

---

# Security policy

This repository is an anonymized portfolio copy of a system used in
production. It contains no live addresses, data or keys.

Please do **not** open public issues for security vulnerabilities. Use the
**"Report a vulnerability"** link under the **Security** tab instead.
Supported version: latest `main` only.
